# V13 Gate-Aligned S3 评估

## 结论

- V13 相对直飞有效，但尚未达到 90 分目标。
- V13 相对 V11 只有小幅、混合改进，不能判定为显著升级。
- 当前 best checkpoint 来自 65,536 步；后续训练发生退化，最佳保存阻止了末期模型覆盖它。

## 与 V11/V12 对照

此前相同范围的 V11 + V12 门控结果为 75.56 分，V13 为 76.02 分，绝对差为 +0.46 分。由于两次独立仿真的直飞基线分别为 66.40 和 64.24，存在运行波动；按各自相对直飞增益比较，V11 为 +9.16，V13 为 +11.78。

因此可以确认 V13 没有破坏整局能力，但现有单种子证据不足以证明它稳定优于 V11。下一步应针对候选 checkpoint 做多种子直接对照，而不是继续沿用本轮末期权重。
