# final20 全图顶层计划敏感性实验

## 协议

- 地图：20 张 final20 地图；每个锚点每图 5 个公共种子。
- 底层固定：`local_avoid_s3`；蓝方固定：`b0_fixed_ratio_random`, ratio=2。
- 同一地图内所有锚点共享 H/M 公开目标分配、L 侦察比例和全暗巢发现门控；只改变锚点声明的部署、波次或编队字段。
- 隐藏目标不出现在战前 token 中；全部合法暗巢发现后，预备 L 才按不同暗巢分组释放；局内不换靶。

## 解释边界

- 配对均差和置信区间用于判断跨图稳定关系；单图最高分只用于定位后续细分区间，不直接作为通用 skill。
- 如果全暗巢触发率低或搜索完成数接近零，部署/波次结论只能解释当前搜索执行器下的系统效果，不能声称完成了严格全域搜索。
- 该实验是确定性计划敏感性实验，不是 MAT 在线学习结果。
